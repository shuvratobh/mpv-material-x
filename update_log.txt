feat: polish uosc UI, fix seekbar contrast, add Remaster & Night Mode, clean bloat, add update_log.txt
--------------------------------------------------------------------
- UI & Visual Polish:
  * Timeline (Timeline.lua / uosc.conf): Restored slim 1.5px/2px seekbar
    (timeline_size=25) with muted gray unwatched track vs. bright #008cfb
    watched progress, crisp handle halo, subtle hover scrub dot, sky-cyan
    chapter diamonds above the track, and hover tooltip finish-time clock
    (timeline_hover_clock=yes). Fixed chapter_range_patterns substring bug.
  * Top Bar (TopBar.lua / uosc.conf): Added smooth top feathered gradient
    shadow, frosted translucent pills (border_radius=6), and live real-time
    clock badge (top_bar_clock=yes).
  * Controls & Buttons (Controls.lua / Button.lua / CycleButton.lua / Speed.lua / main.lua):
    Fixed missing config.color.accent definition so active toggles stay lit in
    #008cfb blue; true-centered middle playback controls; polished hover states,
    badges, and speed pill highlight when speed != 1.0x.
- New Features:
  * Remaster Vivid (uosc/remaster, Alt+r, Sparkle button): Default ON
    (remaster=yes); sets target-peak=140, brightness=0, contrast=4, saturation=5.
  * Night Mode / Voice Boost (uosc/night-mode, Alt+n, Moon button): Toggles
    dynaudnorm audio normalization (@night_mode:lavfi=[dynaudnorm=f=75:g=25:p=0.55]).
  * Binge Mode: Enabled uosc native autoload=yes with keep-open=yes and
    keep-open-pause=no to auto-play next episode without playlist clutter.
  * Lightweight Skip Intro (scripts/skip-intro.lua / script-opts/skip-intro.conf):
    Replaced heavy 100x silencedetect/blackout filter script with zero-overhead
    chapter-based Skip Intro banner (Tab / z, 85s fallback); original script
    backed up to backups/skip-intro.original.lua & .conf.
- Performance & Bloat Cleanup:
  * Removed deprecated tone-mapping-mode=auto from mpv.conf and unknown keys
    from uosc.conf.
  * Removed dead/duplicate scripts and configs: scripts/lock.lua,
    scripts/copy-paste-URL.lua, scripts/menu.lua, script-opts/menu.json,
    scripts/select.lua, scripts/autoload.lua, script-opts/autoload.conf,
    script-opts/SmartCopyPaste.lua, script-opts/uosc_history.conf.
  * Added update_log.txt and exempted it in .gitignore.
